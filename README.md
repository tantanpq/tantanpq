# Hi, I'm Tân

I am building **[PAI — Personal Assistant Intelligence](https://github.com/tantanpq/PAI)**: user-owned intelligence for continuity, useful autonomy, reusable capability, and verifiable outcomes.

I am interested in a simple question: **what would AI look like if it could stay useful to one person across years instead of starting over in every chat?**

PAI is my attempt to explore that question.

## What I am building

A mature PAI should be able to preserve a user's trajectory, understand goals and current reality, continue meaningful work across time, learn from evidence, and act within explicit authority while keeping important decisions with the user.

The project focuses on:

- **continuity** across chats, tools, devices and model providers;
- **user ownership** of intent, memory and important decisions;
- **evidence-backed work** instead of treating generated output as completion;
- **bounded autonomy** that knows when to act, ask, wait or surface;
- **reusable capability** so verified work becomes Skills, workflows, Packs, patterns or products;
- **provider-neutral architecture** where models and executors can be replaced without losing the user's trajectory.

## Public PAI today

The public Open Foundation currently includes:

- **Context Kit 0.1.0** — deterministic bounded context compilation and source-aware resume foundations;
- **W_Flow Core 0.1.0** — provider-neutral replayable work-loop and state semantics;
- **SimLab Core 0.1.0 public pilot** — deterministic synthetic verification with `PASS / FAIL / UNKNOWN`, replay identity and minimized counterexamples;
- public Skills, workflows, runbooks, patterns, case studies and reliability evidence.

The complete **PAI Personal** experience is still under development and is not presented as a supported public product yet.

## Why

AI should reduce the burden of remembering, reconstructing, coordinating and rechecking work. The useful outcome is not more agents or more generated artifacts. It is more time, capability, ownership and autonomy for the person using the system.
